# Projetinho-HTML
Projeto desenvolvido em HTML com a finalidade de praticar a utilização de links e imagens em uma página web.

# Sobre o projeto 
Esse projeto foi desenvolvido como uma atividade de estudo de HTML.

# Funcionalidade 
- Envio de email atráves de um link.
- Download de um arquivo de texto.
- Uso de links para acessar páginas externas.
- Inserção de imagens na página.
- Uso de imagem como link clicável.

# Linguagem utilizada 
- HTML

# Estrutura do projeto
- Título da página.
- Texto de apresentação.
- Link para envio de e-mail.
- Link para download de arquivo.
- Imagem com link para uma página externa.

# Objetivo 
O objetivo deste projeto é praticar conceitos básicos de HTML.
